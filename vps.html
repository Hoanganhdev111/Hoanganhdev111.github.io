Connect to a VPS first, then switch here.

What this is

Pure browser SSH console. No Node.js needed locally. You need a tiny WebSocket relay running on your VPS — it bridges browser WebSocket → raw SSH TCP.

Option A — websockify (simplest)

1
Install on your VPS:
pip3 install websockify
2
Start the relay (bridges port 8023 → SSH port 22):
websockify 0.0.0.0:8023 localhost:22 --daemon
3
Open firewall port 8023 on your VPS:
ufw allow 8023/tcp
4
In the sidebar relay field enter: ws://YOUR_VPS_IP:8023

Option B — tiny Node.js relay (more control)

Save as relay.js on your VPS:

const net=require('net'),{WebSocketServer}=require('ws');
const wss=new WebSocketServer({port:8023});
wss.on('connection',(ws,req)=>{
  const url=new URL(req.url,'http://x');
  const host=url.searchParams.get('host')||'127.0.0.1';
  const port=parseInt(url.searchParams.get('port')||'22');
  const tcp=net.connect(port,host);
  ws.on('message',d=>tcp.write(d));
  tcp.on('data',d=>ws.readyState===1&&ws.send(d));
  tcp.on('close',()=>ws.close());
  ws.on('close',()=>tcp.destroy());
});
console.log('relay :8023');
npm install ws && node relay.js

Relay URL: ws://YOUR_VPS:8023?host=127.0.0.1&port=22

Security note

The relay listens on 8023 — anyone with access can attempt SSH through it. For production: add an auth token check in the relay, or bind to 127.0.0.1 and use SSH tunnel + nginx proxy with HTTPS/WSS.
